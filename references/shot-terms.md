# 把专业词写成观众能辨认的画面与声音

先保留用户指明的术语和参数，再用当镜已有的主体写出它造成的**一个可见或可听结果**。一般的「固定近景」配合具体画面已足够。有几种解释、多个操作同时发生或容易误生成时，写清起点、改变的是哪一项、落点，以及哪一项按原要求保持。成稿只留导演讲戏的短句。表中人、物、方位用实际镜头替换。

## 时间、焦点与透视

| 用户用词 | 写进镜头时抓住什么 |
|---|---|
| 升格（overcranking）、慢动作 | 把原来很快的动作在银幕上展开。如「纸从她手里脱开的一瞬转为升格慢动作，纸角慢慢翻过来，手指还停在刚放开的姿势」。若已给拍摄 96 fps、24 fps 回放，可写动作占时为原来的四倍。只有高帧率或只说人物动作慢时，先看用户的回放意图。 |
| 降格、快动作。延时摄影 | 降格快放时，同一个连续动作在画面内更快完成。延时是间隔采样后压缩较长过程，如光影从桌的一端移到另一端。保留起止状态。 |
| 变速、速度渐变、定格、子弹时间 | 变速注明从哪个动作开始减慢、哪一拍恢复实速。定格是某一帧停住。子弹时间若指定环绕，写主体几乎静止、观察位置仍绕到另一侧。普通慢镜头无需添加环绕。对白或声音速度另按原要求。只在某动作升格时标明从哪一下恢复实速，把原本正常语速的台词留在那之后或原定的声音位置。 |
| 移焦、拉焦、焦点转移（rack focus） | 写清初始清晰对象和接收焦点的对象。如「固定机位。画左前景的杯沿起初清晰。杯子落定，杯沿渐虚，右后方一直在场的听者脸上清楚起来」。沿原构图完成。焦点到脸上时再落可读的表演。 |
| 跟焦、浅焦、深焦、失焦 | 人物走近而跟焦，眼睛一路清楚。浅景深写哪个距离清楚及其前后哪层虚化。深焦让近处、中段和远处已有主体同时可读。故意失焦写从清楚到轮廓散开的对象。单写跟焦不能推出机位也跟着走。 |
| 移轴（tilt/shift） | 目标决定用法。要**校正建筑透视**时，保持机身端正，向上移轴把楼顶纳入画面，两侧立柱仍笔直平行。要**倾斜焦平面**时，让清晰范围沿桌面斜向延伸，使一近一远的指定物同时清楚。要**微缩观感**时，写俯看真实空间，某一带清楚，两侧渐虚，实际街景呈现出模型般的观感。单写「移轴」而场景不能辨义、选错会改变画面时，只问要哪种效果。 |
| 推轨、拉轨 / 光学变焦、急变焦 | 推轨靠近人物，近物与背景的相对位置随观察点改变。固定位置变焦只使取景收紧或展开，透视关系基本保持。急变焦可写「机位不动，画幅迅速收紧到他的眼睛，随即停住」。 |
| 滑动变焦、希区柯克变焦（dolly zoom） | 同时写两项相反动作和稳定参照。如「摄影机靠近她的同时把视角拉宽，她的脸在画面中始终一样大，身后的走廊像被拉长」。若机身后退并拉长焦距，主体仍等大，背景看似逼近。方向由用户与戏决定。 |
| 广角近摄、长焦压缩、微距 | 广角靠近时，最近的物件相对更大，前后距离显得更开。远机位用长焦取相近景别，前后层次看起来更贴近。透视取决于观察位置。微距写画幅被哪个小部位占据、哪处纹理清楚，镜外整个人无需复述。 |
| 快门角、运动拖影、抽帧感 | 同样的运动和帧率，短曝光使运动边缘利落、快动作显得分明。较长曝光使运动方向留下拖影。抽帧感是可见位置一跳一跳。保住用户明给的角度或速度，只写对应画感。 |

## 机位、构图、剪接和声音

| 用户用词 | 转为可执行的描述 |
|---|---|
| 摇摄、俯仰摇、甩镜 | 原处转向，从画左谁摇到画右谁，或从下往上揭示什么。甩镜让已有轮廓在快速掠过时模糊，写明落幅。只在原设计有切点时才切。 |
| 横移、侧跟、环绕、升降 | 横移改变观察位置，近景遮挡与远处背景相对滑过。侧跟指明跟谁、谁停下时镜头是否停。环绕说明绕谁、从哪一侧到哪一侧。升降是观察高度变化。仰拍只交代观看角度。 |
| 手持、稳定跟拍、主观镜头、FPV | 写观察位置、移动路径和地平线是否平稳。主观镜头从角色所在的位置和高度看。若要脸部反应，用用户已有的反打或倒影。FPV 优先写实际穿过的空间和转向，不凭术语加飞行器入画。 |
| 荷兰角、顶拍、越肩、正反打 | 荷兰角是画框相对地平线倾斜。顶拍从正上方看。越肩说明哪侧近处只见肩缘、远处谁清楚。正反打换构图后重写人物在银幕上的朝向，留住原视线关系。 |
| 轴线、越轴、视线匹配 | 常规对话沿两人连线同一侧拍，切后相望方向能接上。有意越轴时按指定走位或机位写清方向何时翻转。视线匹配先让人朝某侧看，下一镜给从该方向看到的目标。被看者原本在画外就到该镜再出现。 |
| 长镜头 / 远景。空镜、插入镜头 | 长镜头指持续拍下一个过程，可以是近景。远景交代大范围空间。空镜保留环境中的可见变化。插入镜头说清切到哪件原有物件或哪一处细节，按剧本决定何时切回。 |
| 动作衔接、匹配剪辑、跳切、交叉剪辑 | 动作衔接在同一个动作中换机位，从上一镜已完成的位置接下去。图形匹配指定两幅画中相似的轮廓及位置。跳切写同一主体哪段时间被略去。交叉剪辑写两条原有行动怎样交替。 |
| 硬切、叠化、淡出、遮挡转场 | 硬切在给定时机直接换画面。叠化期间前后画面短暂重合。淡出逐渐收到纯色。遮挡转场让已有前景盖满画幅，再在遮挡退开时露出下一构图。 |
| J-cut、L-cut、声桥、画外音、内心独白 | J-cut 先听见下一镜的声音，再见下一镜。L-cut 已切画面，上一镜的声音还在继续。声桥交代什么声音连过哪个切点。内心独白时镜内人物不按独白做口型。保住用户指定的声源、原句和听见它的人。 |
| 硬光、柔光、高调、低调、逆光、剪影 | 用影子边缘软硬、亮暗面积及面部可辨程度描述。逆光从人物后方来，脸可有补光。若确为剪影，只交代外轮廓、头部朝向和姿态，等脸被照清再写眼神。低调画面也可保留一小处亮部。 |
| 环境底声、拟音、声场、混响 | 用声音来源、所在方向、远近、空间反射和消退时机表达。如「同一脚步从左后方移近，停在画外，室内只剩既有的风扇声」。拟音写最终要听见的声音。无关的音效道具省去。 |

## 影视以外的词和陌生用语

先判断这个词描述职业动作、成品外观、材料、节奏，还是画面风格。保留专名，把与这一镜有关的「谁使用什么、发生哪一下、观众如何认出」用短句写出。工艺名用于形容画风时，描述成像特征。用于拍工序时，描述镜内原有材料和动作。

| 原意 | 可用的画面或声音 |
|---|---|
| 小提琴拨弦（pizzicato）转弓奏（arco） | 若是演奏特写，指尖拨开琴弦，短音弹出。到换奏法那一拍，弓毛贴上弦，声音随运弓延续。若只作画外现场声，只写短音如何变成长音。 |
| 木刻凸版，或单要木刻版画质感 | 拍印刷就写凸起处着墨，纸揭开时显出印迹。指定画风就写色块边界、刀刻般的留白线等图像效果。画面里没有印刷工序时无需添加版、纸或制作者。 |
| 芭蕾半蹲（demi-plié） | 用已定脚位，膝盖顺着脚尖方向屈下，两脚跟贴地，再伸膝站起。全身景可读脚位和高度。只见上身时只能写躯干平稳下降再回升。 |
| 身段、亮相、留白等跨语境词 | 舞台上有约定动作时写已有的姿态在哪一拍定住、朝向和眼神。构图留白写哪侧空出。对白留白写哪个人没有立刻接话。按项目给定动作或剧种保留准确称呼。 |

遇到表中没有的术语，先用用户定义、分镜上下文和参考的可见事实辨义。仍不确定且含义会改变交付，可查对相应行业的原始资料或只问一个具体的二选一问题。不要凭字面发明手法。轻微遣词差异可以沿用原名，加上已经能确定的效果。
