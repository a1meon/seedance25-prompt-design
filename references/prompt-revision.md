# 已有提示词的逐镜修订

读完整篇，再动笔。先辨认这是一条待优化的文字指令，还是用户在要求修改某段已生成的视频。“帮我优化下面这段提示词”只交付修订后的文字。若文字本身是视频编辑指令，就继续保留原片、局部修改时段与继承条件。

## 先判断偏差来自哪里

针对“上次出了这个问题”先对照当前版本中的具体镜头、当时的原句、有效素材职责和用户眼下想要的结果。区分创作改意和故障归因。原文写“笑了”，用户现在要唇角平直，这是新指示，可以直接改。此前一次笑得过重，而原文已经准确写“只有一点笑意”，不据此断定文字或模型理解有问题。

| 核对结果 | 对当前版本怎样处理 |
|---|---|
| 能指出原句的缺漏、冲突或两种实际可拍的读法 | 只改造成歧义的一处。如“向左后方退进通道”与用户锁定的横向出画相冲突，可换为“沿同一排向画左走出画框”。同一个机位、程度和落点不需要重复写。 |
| 素材职责或任务模式与目标明确冲突 | 改对应的映射、任务表达或设置说明。例：同一段参考被同时写成“原样编辑”和“照此重拍另一画幅”，按真实意图选任务。按本镜实际使用的参考校对人物与方向。 |
| 有适用的 2.5 明确规则，或已有可比对照能把偏差定位到一种写法 | 对当前任务采用已确认有效的写法。区分模型的硬限制与写作建议。结论只及于证据支持的范围。 |
| 原文、参考和设定一致，只有一次或几次表现波动，原因仍不明 | 保留有效指令。即使同一稿曾成功或失败，也不能单凭某次结果判定原因；只有 2.0 旧例同样不足以确认 2.5 会误解。若用户单独问原因，直说目前无法归因。已有结果可比较，无需为改提示词自行提交测试。 |

遇到一次偏差不用在新稿加入一串禁令。只在用户确实要求某种新表达，或有上述可定位依据时改其对应句。举例只说明判断方法。

## 保存原稿的决定

用户反馈“表演太平”时，把相关几镜连起来看。找出只给视线或语气的近景、同一刺激下人人做相同动作的段落，以及连续几镜反复复述同一张脸的地方。从实际机位把清晰可辨的脸逐个对回本镜正文。若一人只剩视线或站位，即使同框另一人的表情已经写全，也要给漏写者补出情绪和面部表现。留下已经有效的一拍。若角色有新的判断或打算，在原句交代是什么让表情起了变化，接着他怎样对待眼前的人。若指定一直对视、全程冷面或延续同一情绪，保住指定项，在仍开放的表情、回应时机或姿态上找区别。增强最关键的一拍时，删掉邻近的同义动作和程度副词，按原稿保留镜数与台词。

内部记下原稿的剧情结果、明确的表演方向、先后镜号、单镜/切镜、可见范围、角色与道具归属、对白原文、原声或音色、素材编号和各自职责。用户只要优化某一项，就只动该项和直接关联的冲突。通常按原稿顺序和语言给一份干净修订稿，保留有效的空间关系、风格、反常构图、诗意和有意悬念；修好局部问题无需重写整场。

**逐人保住已定表演，补本镜的空白。** 原稿只有「她有点失望」，可写成「她有点失望，目光慢慢垂下」。若已写「她始终看着画右」，就沿用目光，只补「她始终看着画右，有点失望，刚扬起的嘴角平了下来」。常规精修扫过同框的听者、配角和有戏的 NPC，在各自原句补足情绪、视线和可读的表现。背影或局部按取景处理。用户只改一人一项时，仅调整那一项及直接受影响的承接，其他人已有的表演照留。逐人核对在内部完成，删去与原动作同义的句子。

## 同一份稿连续改几轮

1. **确定底稿。** 用户刚贴的新稿或明确点选的版本优先。否则，取对话中最近的整稿，把之后已经采用的局部修订按镜号合回。保留有效的表演原句，尤其是反应由哪个字触发、哪一刻才松口、静默的人当时在争取什么。只改走位或台词个别字时照录其他镜头，留意改动是否挪走了反应的起因。起因还在就留住原演法；起因被删，只在受影响的位置重新找依据。讨论过的备选和已否决的走法不算进正文。
2. **把变化写回发生处。** “别退了”“把这里的委屈再收一点”都要落到原位置。换走位就替换原来的起步、路线和落点，再查下一镜承接的位置、朝向、视线与持物。换情绪就换相应表演，撤掉与新分寸冲突的神态。删去在结尾解释“按上一版”“现在改为”的文字。
3. **回读这次增加的每一句。** 同一拍的同义神态选最准确的一笔；若“追视、停留、垂眼”三个时刻合在一起才演得出不舍，可压成「目光追出去，停了片刻才垂下」。同一个仅拍单人的要求放在需要的镜头；音色身份在素材职责处登记，台词在实际发声处写一次。独立提交的分段仍须各自带齐需要的绑定。只换偏好时，局部力求与原句相近或更短。确有新动作、新台词或新镜头时可自然增写，保住原台词、素材编号、关键表演、空间连续和画内外约束。
4. **交付一份可用稿。** 只给整合后的当前正文或用户指定的局部。按[输出校验](../SKILL.md#输出校验)复核交付范围。已写清的摄影和表演原句保留；旧稿漏写运镜时，在相应镜头原句补上摄影选择。用户明令“其他地方逐字不动”时，校验和修改限于开放的部分。清理旧稿中误列为参考的剧本、素材行里的附注和上传提醒。每个独立段先写【生成目标】，把跨镜约束合入最后的【约束】，末行只写一次 `无bgm，无字幕`。

例如原句是「她有些委屈，低下头，抬手擦泪」。用户改成“别哭，撑住”，这一句换为「她有些委屈，抬着脸，下唇轻轻绷住」。随后说“再轻一点，只留眼神”，当前句可以是「她有一点委屈，抬着的眼轻轻垂了一瞬」。三轮下来，镜头里只有此刻要演的反应。

## 逐镜可见范围

在脑中把一镜画成画框。框里是可画的内容；在场但不在框里的对象，仅在影响当前可见反应或必须听见时才处理。这个判断适用于总述、构图、参考职责和结束段，避免总述先列出一串未出镜的人或物。演员分析、词库举例、比喻、人物回忆、台词提到的对象，都不自动成为画面元素。

| 原意 | 提交给模型的写法 |
|---|---|
| 近景中只看见阿岚，她有些期待地望向画外一位沉默的人 | 「单人面部近景。阿岚望着画右，有些期待，嘴角刚刚扬起，安静地等着。」只写画内这一张脸。 |
| 戏靠画外说话触发 | 「本镜只拍阿岚。声音从画右传来，父亲仅以画外音说 {坐吧。}，全镜不入画。话落后，阿岚原本准备应声的嘴唇合上。」保留音色绑定。原台词即使提及未出现的人物或物件也逐字保留，不再在画面句复述。 |
| 只闻声的物件 | 只需要节奏，写「<画外响两下短促的金属声>」。来电铃、报时钟等身份关系到剧情时保留其特征声，必要时写「仅作画外声，镜头始终停在她脸上」。静音场景靠已给的可见线索转折。 |
| 只拍手、倒影、肩缘或影子 | 写实际可见的那部分，如「右下前景只有一截虚焦肩线」「画幅由镜面填满，镜中只有师妹一个全身倒影」。局部已入画，用准确裁切描述。留意玻璃、屏幕、照片、镜中像是否本就被指定为可见。 |
| 对象中途入画、出画或到下一镜才揭示 | 只在需要时交代边界变化。例如「前半镜只见她的手停在桌边。敲击声落下，信封从画右滑入，停在她指尖前」。已移出画面的东西无须再报位置。 |
| 独立提交多镜、素材参考里有多人 | 必要的绑定仍保留。给单镜单独提交时只激活该镜所需的参考和声音。整段提交时，素材栏只写简短的用途映射，具体哪一镜可见、哪一镜仅闻声写进该镜。 |

限制的强度随误生风险调整：可省略，就直接省略；涉及方向，就写方向；必须点名的画外声源，才用一句「仅闻其声，本镜不入画」。明确要求单人、当前稿却同时写出另一个可见主体时，可用「镜头始终只拍某人/某物」锁住构图。避免用否定句列举本来完全无关的人、物和装备。

## 把可能拍成两种结果的句子改清楚

| 歧义 | 修订时的判断 |
|---|---|
| “她看她，然后把它递过去” | 分清谁先动、谁反应、物体从哪只可见的手到哪一侧。同框才逐人点名；单人镜头直接写主体的动作。 |
| “固定镜头推近”“一镜到底，切脸部特写” | 先找用户锁定的是机位、镜头连续性还是最终大小。固定机位可以由人物靠近改变占画幅比例；允许推近时是摄影机移动。二者的画面含义不一致时，依上下文取最有依据的读法。两项都被用户明确列为不可动且影响成片时，才集中确认。 |
| “他在左边向右转”“更远一点” | 明确银幕方位、人物自身左右、人与镜头或与道具的距离。写动作后落在哪一侧；若原文只想表达移焦，就写近处由清转虚、远处由虚转清。 |
| “先震惊又愤怒又释怀，眼神有戏” | 找产生下一层感受的证据。一个短镜只保留它装得下的关键变化；多个已定转折则利用原有镜头和声音承接。语意故意留白时，只强化观众此刻应该察觉的变化。 |
| 时间、说话者、音口或素材绑定会串 | 保留原镜号、指定时间段和原句。把关键动作放在对应词或声响之前/之后，用画内、画外、旁白明确发声方式。继承既有 @ 编号，新增音色用空闲号。不要把动作参考写成该人的外貌或把声音参考中的讲话搬来当台词。 |
| 文字可能被画成实体或特效 | “眼里藏着一场暴雨”“仿佛看见童年的家”如果是写实心理比喻，改成片中人能看到的短促反应；若明确要倒叙、主观幻象或真实降雨则照留。把只服务声音的物件移出画面句。 |
| 互相抵消的笼统修饰 | 保住有实际结果的要求。已有「固定中景，侧光只落在右脸」就用它；若“镜头充满冲击力”没有新增可见结果，可以删。不为优化附加画质词、背景物或通用负向词串。 |

## 一条已有提示词的完整修订

**收到的原稿**　「镜12固定，只拍青禾脸，右边。她脑子里都是父亲那只坏掉的表。门外老周攥着帽子说‘他走了。’她看看他又看看表，泪崩但强忍，别切镜头，@音频3老周音色。她最后还是把话咽回去。表和老周都不要拍。」

**可提交正文**

> 【生成目标】
> 用一个固定近景拍出青禾听完画外的答复，想追问又把话咽回去的瞬间。
>
> 【参考素材职责】  
> @音频3为老周的音色参考。
>
> 镜12，固定面部近景，全镜只有画面右侧的青禾。她原本抬着眼等回话。老周仅以画外音说 {他走了。}，本镜不入画。听完，青禾先是错愕，嘴还微张着，像要追问。她低下眼，眼眶慢慢湿起来。那口气停在开口前，最后她轻轻合上嘴，没出声。
>
> 【约束】
> 无bgm，无字幕

这里把「泪崩但强忍」按已给结尾落实为将要失守又忍住。视线的降低保留对原有记忆的反应，画面无需重新造出一只表或一顶帽子。若用户明确规定泪必须落下，就保住落泪，让克制表现在仍然没有把那句话说出口。
