# Seedance 2.5 常见问题处理

写新稿时，只处理任务本身涉及的风险。排查偏差时，用原稿、实际素材和生成设置定位到下面的情形。符合某个现象只说明值得检查，不能据此断定这次的原因。用户要提示词就交付可粘贴的正文。用户问成因或设置，才说明素材处理、参数、后期或仍待确认的环节。

## 角色、文字与画面

| 遇到的情况 | 如何决定、写到哪里 |
|---|---|
| 2.0 与 2.5 的镜头接在一起，画风跳变 | 需要接着旧片讲下一拍且已有 2.0 成片时，用旧片作延长母版，目标写清从末帧的光色、位置和动作继续。输入、输出可选 MOV 以改善衔接。若只是用同一组图重新拍新戏，按新戏写可见的风格，不能声称已承接旧片。 |
| 写实人物因情绪描写出现发光瞳孔 | 把光效比喻换成普通情绪词和自然表演。保住指定强度，如「他惊得话没说完，眼睁大了，视线钉在画右」。针对已出现的发光问题，在约束固定首行之后优先写正常眼睛、瞳孔不自发光。有彩色环境光时说明只勾面部轮廓。原设定明确要超自然眼效时照原戏。 |
| 角色、造型或声音串位 | 对照每个角色首次入画或画外发声的时刻，逐项核对上传顺序、真实槽位及身份。能规划时按首次出场安排人物参考，同步对应图与音色。已有槽位即保留原绑定。讲戏和发声处按姓名落回本人。详见[素材与音色排序](performance-workflow.md#排素材与音色)。 |
| 必须看清的英文或中文写错 | 确定原字串、载体和位置。英文若本来就要逐字显现，可按字母拆开依次呈现，再给完整结果。若一开始就该看见整块牌，保留其静态呈现。精确中文字样或难拼的标识优先用已有的准确文字图作参考，在职责栏命名，镜内写「门牌正面沿用门牌字样」。缺图时直接写原文。诊断时可建议制作字样图。 |
| 已写无字幕仍自动上字幕 | 先查有没有在讲戏句里再次引用台词片段，有没有沿用带字幕的参考视频。把语气放在每个原分句之前，让听者在「称呼出口时」「句末」反应。保留剧本原本的重复。优先使用同源净版，区别对白叠字和剧情所需的场内文字。见[声音、台词、文字](seedance-format.md#声音台词文字)。 |
| 高分辨率参考图的草叶等细密纹理变成指纹、鞋印 | 检查输入图和目标视频的像素尺寸。对适用的高分辨率 AI 图，准备一份等比例缩小、像素尺寸不超目标输出的副本。输出可选时，官方观察到 1080p 比 720p 较少出现此现象。主体、镜头与材质写对时保留原句。 |

## 任务、时长与素材

| 遇到的情况 | 如何决定、写到哪里 |
|---|---|
| JPG 上传或解码失败 | 非常规色度采样是可能原因。准备标准 4:2:0 JPEG，或另存为 PNG 后重新上传。需要具体转换示例时可用 `ffmpeg -i input.jpg -pix_fmt yuvj420p fixed.jpg` 写到新文件。改扩展名不能改变编码。 |
| 严格编辑后片尾少了约三分之一秒 | 若必须原片编辑，优先核对源片帧数。可将输入副本调整为 8n+1 帧（n 为正整数，如 241 帧），并核对帧率与声音落点。若精确秒数更重要且允许重生成，改用参考生成并在设置里指定支持的时长。严格编辑沿用母版时长，正文不许诺逐帧相等。 |
| 一次要求多项参考和编辑，结果不稳定 | 按依赖拆任务。先依动作或走位参考生成需有的轨迹，再把该结果作为编辑母版完成局部清理或替换。各段保留用户的镜号、切点和接点，必要时由后期拼接。若用户锁一镜到底，可分次处理同一条连续素材，不为拆任务切断画面。 |
| 改横竖画幅后凭空补景、切点错位 | 先辨认是否真要改画幅。要重构画幅，使用参考生成，明确目标画幅，对照原片逐镜写内容、时序、切点和新边界内必须完整保留的主体。选严格编辑时，画幅随母版，时长由原片决定。仅要求等比裁切且不许重构时，裁切属于后期选项。 |

## 音乐、翻译与噪声

| 遇到的情况 | 如何决定、写到哪里 |
|---|---|
| 禁配乐仍生出旋律或铺底音 | 先列本片实际允许的声音。若有这项故障，在【生成目标】开头的事件概述旁先交代可听声源，在【约束】固定首行之后再强化一遍。集中排除配乐、器乐、旋律、合成器铺底、持续氛围乐音等音乐性声轨。要保留脚步与环境声就点名保留。全片只要人声才写只留人声。若剧本有人在镜内演奏，保住指定的现场演奏，排除另加的配乐。后期分离人声可去掉其余声部，也会丢掉音效，仅适用于接受该结果的情况。 |
| 翻译视频时残留原语、声线串人、口型错位 | 按源片的实际时间段列出说话人和完整目标语台词，含可辨识的背景对白、低语、感叹、语气词。已有目标语原句照用。低声说出的台词也要译出并保留其音量。把背景残留的原语替换成该人的目标语，禁令只针对原语残声。对每个出声者按姓名核对音色绑定，画内逐字对口型，画外继续画外发声。覆盖全片可辨语音，约束写清目标语、清除原语残声、保留原画面其他部分及指定环境声。无对白叠字。听不清或没拿到台本和时点时保住未知范围，不编译文和秒数。 |
| 无端出现冒泡、水波声、回音或细小啸声 | 检查声音句、修辞和环境描述里与水、波动、回响有关的误导词。如「声音在心里泛起涟漪」可改成听者的面部反应。确有水面入画就保留水面。原戏是隔窗无声地看水，声音写室内实际可闻的内容。确需水声或回声时，保住该声源与强弱。 |

翻译片的素材职责也只写映射句，例如「@视频1为走廊母版的画面、原对白时点和脚步声参考。」两位角色的音色各列一行。镜内可写「后景人物声音比前景轻，仍能听清」。若需要限制残声，写「所有可辨识的中文对白换为日语，保留后景人物低声说出的日语答句」，使要保留的低语有明确归属。
