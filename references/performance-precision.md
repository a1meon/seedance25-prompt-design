# 表演分辨与声音

## 真人近景的改写办法

先判断是一个已经存在的状态，还是情绪正在变化。固定近景可以写「她神情失望，眼皮微垂，目光一直落得很低」。若给的是强作平静，嘴唇可以短暂绷紧，再恢复平常的神色。保留原词帮助把准人物的感受，以表演决定观众能看到多少。

- **持续状态。** 开场就委屈，可以写「她一直有些委屈，下唇轻轻绷着」。没有指定起因、对白或后续转折时，保持这个状态即可。
- **刚刚产生。** 从有期待到失望，可以写「原本抬着的眼慢慢垂下，脸上的期待淡去」。先前就低着眼时，另选符合起始姿态的表现。
- **克制和外露。** 同样的委屈，克制可以是「她有些委屈，嘴唇动了动，又轻轻合上」。外露可以是「她满脸委屈，眼眶慢慢湿起来」。挑符合人物习惯的一种。是否哭、是否说话由原稿决定。
- **复合情绪。** 原文说“既高兴又心酸”，两者可以共存。原文说“先高兴，随后失落”，可让笑容慢半拍才退去。写掩饰时则交代表面呈现什么，以及观众能察觉多少。给情绪保留它原有的方向。
- **景别和声音。** 正面近景适合唇线、眼神和眉间的细微变化。侧面看轮廓和朝向，背影看头和肩，远景看重心和动作节奏。画幅只容下一张脸，就在脸上完成表演。说原台词时可以改变气口或重音，闭唇、抿嘴等安排在停顿处。静音镜只取可见部分。
- **极轻的演法。** 原稿要的是静、钝或难以察觉时，可以写「他有一点失望，低垂的视线久久没移开」。静止的姿态有形状、有朝向，也可以有持续时间。夸张风格则按原文放大幅度与节奏。

写笑容时，留意它起得快慢、在哪一处停住、如何淡去。同样的嘴角上扬可以是真心、客气或勉强，依原文明确情绪和分寸。

## 把导演的分寸讲清楚

- **给眼神一个去处。** “高冷但有点失望”可写「他听完，只朝画右看了一眼。目光收回来时稍低了一点，嘴仍自然合着」。他可以继续维持原来站姿。长久盯视、用力抿唇、红眼是更强或不同的选择。用户给的身份不能替代当下的情绪。
- **先听懂，再反应。** 某句话里的称呼引起疑惑，听者在称呼前仍照常倾听，听到称呼才抬眼，眉间略微一收。只让主反应者露出这一下，其余人可以继续原动作。要使对白跨切，按原切点分配原句片段，前后顺序和标点接回去须与原句一致；说明同一声音连续，下一镜画外接完。用“听到这个称呼时”指回台词里的词，避免把词再写成一次发声。
- **缓和也有分寸。** 从不想理会到愿意听，可写「她终于转过脸，目光落稳，唇角保持平直」。表情只有轻微变化时，收小的是幅度，保留下来的是注意力的改变。对方察觉与否以剧本为准。
- **检查每个角色的全段情绪。** 按人物逐段对照原文，包括持续的底色、刺激前后、外表和内心是否一致、没说话的人何时知情。只选镜头要展示的部分。一个词查不到或黑话有歧义，拆成“想靠近还是避开、在争取还是已经放弃、有多外露”，用原词加可见表演。写混合情绪时保留两层，不用最接近的单词覆盖另一层。
- **表演词和人物判断分开。** 微笑、哭泣、吞咽、眨眼首先是可见动作。自然微笑可以含礼貌，眼里有泪也可以是高兴。按角色处境定含义。用户没有给出的感受不凭单个表情、肌肉、年龄或性别推断。

## 同一可见动作怎样分辨

| 共同表现 | 可选的细微区别 |
|---|---|
| 低下眼 | 羞涩可以低着眼微微一笑。委屈可以低下眼，嘴唇仍紧着。失望可以在垂眼时让原有期待渐渐消退。 |
| 笑 | 喜悦的笑可以自然展开。礼貌的笑幅度较小，收得干净。强颜欢笑可以让唇角维持片刻，眼神仍显疲惫。 |
| 沉默 | 平静可以安稳地保持姿态。震惊可以停在半途。压怒可以仍抬眼直视，下颌略绷紧。 |
| 发抖 | 受惊的收缩来得快；后怕可以在肩膀放松后才发颤；面对疼痛也可能短暂发颤。情绪由原意确定。 |
| 注视 | 专注时目光可以随目标细微移动。心动可以想移开又转回来。挑衅可以抬着下巴保持直视。 |
| 含泪 | 快乐可以含泪笑开。心酸可以忍着笑，却慢慢安静下来。悲伤可以只是眼里有泪，神情很静。 |

## 有原台词时选择声音表现

保持原词和说话人。相对于此人平时的声音，温柔可以轻起声、语尾柔和；压怒可以降低音量、咬字清楚；急切可以起声较快；委屈可以在一个自然停顿处稍缓，再把后半句说完。要无声就采用脸或身体的一种演法。角色带着情绪也完全可以照常说话。原文要求维持平静或不让听者察觉时尤其如此。

## 类型与身体可见性

写实戏选适合当前强度的反应，近景可以极小。武戏的情绪可用收势、站定或重心变化和现有动作连接；用户给的胜负和动作结果决定这一镜准许发生什么。戏曲、喜剧或夸张风格可以放大姿态、时值和语气，保留用户指定的程式。群像按已有主次安排反应，允许其他人照常行动。详细的构图与切点见[分镜与调度](staging.md)。

词表未命中时，先保留用户的情绪词，确定它是内心感受、对外态度还是情绪转折，再选本镜能表现的一个变化。
