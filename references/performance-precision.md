# 表演分辨与声音

## 表演的力度与时机

先替演员回答“我在等什么，我听懂了什么，现在还愿不愿意让对方看出来”。第一镜也有来处，可以承接前一场已经发生的事。把答案压进观众能看到的一两句。比如「她一直望着画左，原本已经笑着要点头；听清最后两个字，点头停在半途」。如果光给“意外、目光一凝”，就丢掉了她原先准备答应这一层。每个人的反应只用他已经接收到的信息。

| 难演的情形 | 导演如何落到表演上 |
|---|---|
| 直视、坐姿或头部方向已锁定 | 把指定项固定，选仍能动的地方。同样抬眼直视，真心欢迎可以是「认出来时，两颊抬起来，笑容露了齿」；有所保留可以是「客气地扬了扬嘴角，等对方说下去，笑已经收了」。取真正符合关系的一种。 |
| 人物从看甲转去看乙 | 两次注视可能有不同用意，如向甲求肯定、对乙装作有把握。依剧本可写「望向画左时，眉头还皱着等答复；转向画右前，她先把眉间松开，再抬脸笑给对方看」。若两次注视服务同一意图，可让原表情贯穿。 |
| 人物安静、镇定或有威严 | 找出他主动做的选择。安抚别人时可以「微笑着听完，见对方还有话，刚要开口又停下来」；有把握地等别人表态时可以「眉梢抬了一下，给对方留足回答的时间」。若用户专门要求面无表情，把戏落在回应快慢或已有动作上，脸维持原态。 |
| 强情绪与强忍 | 给足剧本指定的强度。压不住的喜悦可以笑到一句话断成两截；憋屈到快哭可以下唇发颤，等它稳住才答。真正放声大笑或痛哭时，用声音、肩胸起伏或动作中断承接爆发。演员强忍时，明确原本要露出什么、怎样收住。 |
| 听、说、被打断 | 发话人想哄、试探、说服还是拒绝？把态度写在起声前的脸、原句中的重音或一句说完后的期待上。听者原先怎样听，到了哪个字才听出另一层意思？抢话有急切、维护或故意压人等不同用意。被打断者还没说完的神情可以留到下一个能看清他的镜头。口型在发声处始终服务原台词。 |
| 混合感受或故意遮掩 | 一层给对手看，一层给观众察觉；也可以两层同时真切。比如「她笑着点头让对方放心。等对方转开，她的笑还挂着，却已经撑不住刚才的幅度」。若两层同时发生，先定哪一层给对手看，再按景别选一个泄露分寸的迹象。眼眶里还留着泪，原本躲开的视线已经能稳稳迎回去，可以承接悲伤中的决心。只有剧本允许观众察觉时才给这一下。 |
| 无对白、喜剧或动作戏 | 无对白可让原本要做的事迟一步、做了一半或终于做完。喜剧可让演员先一本正经地等，听懂后才忍不住笑。运动中脸读不清，用动作突然变急、迟疑或收势不稳；等人物站定、脸重新可见，再读出得意、懊恼或后怕。 |

**连续几镜要有轻重。** 给每个关键角色找出这一段真正改变想法的一拍。入镜接上前态，变化落在刺激之后，镜尾留下的反应带进下一镜。剧本指定情绪持续时，同一种感受也有过程：起初试着含住笑，之后是在忍笑，最后可以还带着那份高兴平静下来。若连表情也要求持续，就把同一形状接准确，镜尾的停留本身就有作用。对普通过程可以一笔带过；转折或爆发处用清楚的动词，按戏决定持续多久。连续写“微微、轻轻、略微、停一拍”会把不同力度写成同一档。

**按观众实际读到的大小来写。** 清晰近景可以让笑先在眼周起来、嘴角随后才动。中景选轮廓清楚的表现，如原本打算迎上去，认出对方神色后脚步停住，上脸的笑也停在那里。脸被前景遮挡时等它重新可见；全身远景读步幅与重心，纯背影读肩背和动作的完成程度。镜头很短，就让观众看清一件事。用户只锁住眼神、台词或走位时，其他表演仍可发挥。

**同场人物要能分得开。** 两人同样高兴，一个可以马上迎上去分享，另一个可以先等对方说完，才笑得露了齿。一个人很伤心却在安慰别人，难过的程度可以很深，对外仍温和，最吃力的是要把安慰的话接下去的瞬间。以剧本和人物惯常做法分配差别。若换掉姓名后几人仍在同一时刻以同一种方式抿嘴、低眼、顿住，挑出最影响剧情的一人重写动机与反应，其余人的有效动作照留。配角也有自己的注意对象与节奏。

**辨认容易看错的一笔。** 背影垂肩可能是失落、疲惫或放松。先看人物正在做的事因什么停下来，又朝谁继续做；把动作接在原有刺激之后，观众才有线索辨别。同一取景仍难以区分复杂感受时，用相邻镜头里已经可见的表情先铺一层，背影镜承接另一层。用户锁定的单镜就演其中确实可见的部分。

## 真人近景的改写办法

先判断是一个已经存在的状态，还是情绪正在变化。固定近景可以写「她神情失望，眼皮微垂，目光一直落得很低」。若给的是强作平静，嘴唇可以短暂绷紧，再恢复平常的神色。保留原词帮助把准人物的感受，以表演决定观众能看到多少。

- **持续状态。** 开场就委屈，可以写「她一直有些委屈，下唇轻轻绷着」。没有指定起因、对白或后续转折时，保持这个状态即可。
- **刚刚产生。** 从有期待到失望，可以写「原本抬着的眼慢慢垂下，脸上的期待淡去」。先前就低着眼时，另选符合起始姿态的表现。
- **克制和外露。** 同样的委屈，克制可以是「她有些委屈，嘴唇动了动，又轻轻合上」。外露可以是「她满脸委屈，眼眶慢慢湿起来」。挑符合人物习惯的一种。是否哭、是否说话由原稿决定。
- **复合情绪。** 原文说“既高兴又心酸”，两者可以共存。原文说“先高兴，随后失落”，可让笑容慢半拍才退去。写掩饰时则交代表面呈现什么，以及观众能察觉多少。给情绪保留它原有的方向。
- **景别和声音。** 正面近景适合唇线、眼神和眉间的细微变化。侧面看轮廓和朝向，背影看头和肩，远景看重心和动作节奏。画幅只容下一张脸，就在脸上完成表演。说原台词时可以改变气口或重音，闭唇、抿嘴等安排在停顿处。静音镜只取可见部分。
- **极轻的演法。** 若指定失望很轻且始终低眼，可写「他仍低着眼，先前带笑的两颊松了下来，就这样静了一会儿」。只有进镜时已经在笑才借这份残留的笑来演。若进镜时已失望，就从此刻的状态写起。夸张风格按原文放大幅度与节奏。

写笑容时，留意它起得快慢、在哪一处停住、如何淡去。同样的嘴角上扬可以是真心、客气或勉强，依原文明确情绪和分寸。

## 把导演的分寸讲清楚

- **给眼神一个去处，也给这张脸一个态度。** 同样是“看着画右”，若角色盼望肯定又怕显得在意，可以写「他看着画右等答复，嘴角已经扬起来，察觉自己笑得太早，才把笑收住」。若他已经放弃争取，则可写「他看向画右，本想分辩，嘴唇刚张开又合上，任对方把话说完」。只选原戏支持的用意。
- **先听懂，再反应。** 某句话里的称呼引起疑惑，听者在称呼前仍照常倾听，听到称呼才抬眼，眉间略微一收。只让主反应者露出这一下，其余人可以继续原动作。要使对白跨切，按原切点分配原句片段，前后顺序和标点接回去须与原句一致；说明同一声音连续，下一镜画外接完。用“听到这个称呼时”指回发声时刻。语气有变化就把演法放在对应分句前，台词在整段只按剧本实际说出的次数出现。
- **缓和也有分寸。** 从不想理会到愿意听，可写「她终于转过脸，目光落稳，唇角保持平直」。表情只有轻微变化时，收小的是幅度，保留下来的是注意力的改变。对方察觉与否以剧本为准。
- **检查每个角色的全段情绪。** 按人物逐段对照原文，包括持续的底色、刺激前后、外表和内心是否一致、没说话的人何时知情。只选镜头要展示的部分。一个词查不到或黑话有歧义，拆成“想靠近还是避开、在争取还是已经放弃、有多外露”，用原词加可见表演。写混合情绪时保留两层，不用最接近的单词覆盖另一层。
- **表演词和人物判断分开。** 微笑、哭泣、吞咽、眨眼首先是可见动作。自然微笑可以含礼貌，眼里有泪也可以是高兴。按角色处境定含义。用户没有给出的感受不凭单个表情、肌肉、年龄或性别推断。

## 同一可见动作怎样分辨

| 共同表现 | 可选的细微区别 |
|---|---|
| 低下眼 | 羞涩可以低着眼微微一笑。委屈可以低下眼，嘴唇仍紧着。失望可以在垂眼时让原有期待渐渐消退。 |
| 笑 | 喜悦的笑可以自然展开。礼貌的笑幅度较小，收得干净。强颜欢笑可以让唇角维持片刻，眼神仍显疲惫。 |
| 沉默 | 平静可以安稳地保持姿态。震惊可以停在半途。压怒可以仍抬眼直视，下颌略绷紧。 |
| 发抖 | 受惊的收缩来得快；后怕可以在肩膀放松后才发颤；面对疼痛也可能短暂发颤。情绪由原意确定。 |
| 注视 | 专注时目光可以随目标细微移动。心动可以想移开又转回来。挑衅可以抬着下巴保持直视。 |
| 含泪 | 快乐可以含泪笑开。心酸可以忍着笑，却慢慢安静下来。悲伤可以只是眼里有泪，神情很静。 |

## 有原台词时选择声音表现

保持原词和说话人。相对于此人平时的声音，温柔可以轻起声、语尾柔和；压怒可以降低音量、咬字清楚；急切可以起声较快；委屈可以在一个自然停顿处稍缓，再把后半句说完。要无声就采用脸或身体的一种演法。角色带着情绪也完全可以照常说话。原文要求维持平静或不让听者察觉时尤其如此。

## 类型与身体可见性

写实戏选适合当前强度的反应，近景可以极小。武戏的情绪可用收势、站定或重心变化和现有动作连接；用户给的胜负和动作结果决定这一镜准许发生什么。戏曲、喜剧或夸张风格可以放大姿态、时值和语气，保留用户指定的程式。群像按已有主次安排反应，允许其他人照常行动。详细的构图与切点见[分镜与调度](staging.md)。

词表未命中时，先保留用户的情绪词，确定它是内心感受、对外态度还是情绪转折，再选本镜能表现的一个变化。
