# 从戏意到表演

## 从人物眼下所知的事读这场戏

先把这一场读到结尾，再回到该镜开头。找最近一次改变关系或处境的事实，可能是前一场的一次回避、已经给过的答复、一次没被接住的玩笑，也可能只是手头的事刚忙完。结尾能校验前面的分寸，人物只在自己听见、看见或本来知道之后才作反应。截取剧本的首镜同样接着前情。已经拍过的事留在内部，正文从它留下的表情写起。例如安慰已经说完，开镜可以是「她眼里还含着泪，已经能朝画左笑一下了」。前情缺失时从眼下确知的动作起笔。

用户明确给的情绪、脸、视线、时点和走位各自锁住。其次取剧本明写的行动与台词，再用相邻反应、人物关系和处境判断潜台词。角色说自己高兴，可能是实话，也可能在替人解围。先看他说给谁听、说完是靠近还是结束交谈。反读一次：如果他真在庆贺，哪一处支持？如果他是在维护体面，哪一处支持？证据能分出高下就选一种；两种都成立而剧本有意留白，就写两种读法共有的外在选择，不替角色揭底。人物的年龄、身份或类型片惯例不能单独决定反应。

关键拍可以在心里替每个角色说完一句话：「刚才发生了什么，我指望眼前这人怎么做，这个回应对我够不够，我又肯让他看见多少？」挑真正改变演法的一项。回应已有着落时，人物可能在消化好消息、给对方余地、还想确认对方是否当真，三种感受会把同一个点头接成不同的戏。普通交接、独处的自在或持续的哀伤无需制造隐藏目的。

## 用演员做得到、观众辨得出的反应来写

把解释换成有对象的行动，如等对方说完、让对方安心、想争一声认可、试着把拒绝说得体面。再找这个人本来正要做什么。支持他的信息到了，动作可以做完；消息来得太早、落空或被打断，动作可以停在将成未成的地方；执意隐瞒的人也可以把原动作照常做完。决定他何时懂、先露出哪一点、接下来怎么对待对方。镜内只演有用的一段，不必人人都先惊后收。某声响承担打断的戏时，拿掉那声响读一遍：如果前后完全一样，找到究竟是谁的哪一下被截断，或写清他有意把哪个表情保持到声音过去。尤其留意正在被正拍的那个人。另一人转头或抢话，只能说明另一人接收到了声音。若正拍者的心愿或冲动恰在此处落空，把关键变化放回他脸上，即使目光从未挪开。

| 同一限制 | 前情带来的不同选择 | 可写入镜头的短句 |
|---|---|---|
| 单人近景，始终看画左，原词都是「好。」 | 她盼了很久，对方刚把决定权交还给她。 | 她一直看着画左，听完才露出如愿的笑。笑意还在两颊，她就清清楚楚地答 {好。} |
| 同样的近景、视线和原词 | 她刚争取过一次，已经听懂对方的拒绝，要体面收场。 | 她仍看着画左，有点失望。嘴唇张开像要再争一句，合了一下，才平声答 {好。} |
| 两人清楚同框，听到同一结果 | 一个人需要确认，另一个早已知情，正在给他勇气。 | 左边的人不敢先高兴，望向右边，笑才起来就停住。右边的人欣慰地迎着他的目光，郑重地点头，左边的人这才笑开。 |
| 独处无台词，同一件原有的事做了两次 | 第一次是埋头工作，第二次因心神刚受扰，靠熟悉的动作撑住。 | 第一次她专注地低眼，手上动作一气做完。后来仍低着眼，脸上有些茫然，手已经做完，隔了一会儿才松开。 |

这些是对读练习。写用户的镜头时要换回原有人物、原话、动作和时点。脸已锁定就从可见范围选别处或选时机。一直对视的人可以笑得迟、原先要应声的嘴先停住，也可以终于让本来礼貌的笑彻底展开。整张脸被锁为平静且剧情不许露馅，就写对手看见的镇定，以及人物在原动作上留给对方的时间。强情绪允许动作很大；人物突然失声、明明得偿所愿却一时笑不出来，也可以很有分量。避免逐一调动眉、眼、嘴、下巴来证明强度。

## 让同场每个人都活在自己的处境里

- **谈判、告白、和解。** 说者是求一个明确承诺、试着修复信任，还是已经愿意接受拒绝？听者是被打动、暂肯听下去，还是给个礼貌的答复？看两人承担的代价，分别写各自能让对方看到的程度。安静一方的一次松口、没接上的笑或终于应声，都可以落成这一镜的重点。
- **喜剧、难堪、礼节。** 想把事办好的人往往很认真。谁先发觉气氛不对，谁还在等一句回应？用发现的时差或继续做原事的郑重产生喜感。只有原戏支持时才让演员发笑。
- **悬疑、隐瞒、权力。** 分开知情人、不知情人和观众收到信息的先后。真正受威胁的人可能努力让对方放心。要观众也相信时，让这份安抚完整成立；要观众先起疑，才留一次来得太早或收得太晚的反应。
- **失去、宽慰、矛盾感受。** 先定两份感受分别指向谁或什么。为别人由衷高兴时，分享的笑可以完整；等分享结束，自己的失落才有地方出现。两种感受同时存在也可以分落在同一动作里，比如笑着送别，说到原句最后一个字声音才紧。原文只写悲伤时，也允许从头到尾安静地悲伤。
- **比赛、追逐、银幕对峙。** 先认出这次停顿是尚未决定、在确认结果，还是结果已定而身体刚缓下来。运动中用步伐、收住或恢复原动作表达，画面能看清脸时，再把被认出、失望或松口气落实到脸上。保护已给的动作结果和人物视线。

重新合并整稿时，核对关键反应是否还发生在那一句、那一声、那个动作上，以及不同知情时间是否还分得开。需要压字，先删重复的气质和程度词，留下让观众认出人物用意的那一下。
