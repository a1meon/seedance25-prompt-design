# 银幕动作、表演与接镜

先从剧本找这一场交锋改变了什么。谁起初占主动，哪一拍关系或局势变了，结束时各自在什么位置、带着什么感受？没有分镜时，让这些信息决定镜头；已给分镜就把动作和反应安放在原镜内。竞技、追逐、群戏与武侠都有各自的节奏，镜数和时长按这一场来。

## 用画面交代动作

1. **先让观众分得清人。** 在能看清空间的机位标明实际入画的人、远近、面对方向及已有道具的归属。如果开头锁定局部，就从这个局部开始，在第一次允许的较宽镜头交代双方位置。对手尚未入画时，视线和已有声音可以先建立来向。
2. **让一个动势读完整。** 连续一轮动作可以概括。只详写决定结果的那一下，以及结束时观众看到的姿态、方向和距离。两人交错时，用姓名或稳定称谓写“谁从哪边过，分开后谁在哪边”。同一句里互换主语、两人长时间完全重叠、持续环绕又接连切特写，容易把人物关系写乱。若用户已指定复杂运镜，保住它，收简次要动作，写明相机最终看着谁。
3. **选择该近还是该远。** 两人的全身、步幅、先后和距离决定胜负时，让观众看见两人。一个人决定停手、服气或迟疑时，可以在原动作落定后留给他的脸。固定远景可让那个本来还往前的人站住；固定脸部近景可用目光与已有画外声交代逼近。观看重点改变才值得换镜。
4. **接住同一次动作。** 切镜前记住谁在移动、往什么方向、是否已落地或交接。下镜从这个进度继续。双方同框清楚交换站位可以改变画面左右；相机换边时，用连续运动或一个能重认方位的镜头交代。道具、服装和身体朝向以当前镜头能见的部分为准。原声中的落步或衣料声可以跨切，让动作听起来仍是一次。
5. **让演员有不同的余波。** 急于证明自己的人停晚半拍，沉得住气的人已经站稳；怕输了面子的人可以先端正姿势，等抬眼时才泄露失落。用“发生在什么时候”区分体力、疼痛和后怕。情绪的结果留给观众看见，胜负与伤情沿用剧本。

## 核对动作描述

下表是在原句可定位到相应问题时的改法。成片偶尔换边、粘连或轻飘，也可能出现在准确的提示词下。先按[成片偏差的判断](prompt-revision.md#先判断偏差来自哪里)排查；核对后仍无依据，就保留原句。武戏的运镜和分镜同样服从用户设定，只补开放的决定。

| 核对原稿时要问什么 | 对应表达确有缺漏时怎样改 |
|---|---|
| 动作主语或外观映射是否混用 | 把“他们又转过来”改为各自的运动方向和分开后的站位。可用已有外观参考分别绑定身份。 |
| 脚本是否要求交接被完全遮住，又要看清交接细节 | 把最重要的一次交接放在可见侧，写清交接前后由谁持有。其余动作简述。用户锁定遮挡时，把结果留在重新可见的时刻。 |
| 原文要求有重量的急停，却只写了最后一个姿势 | 先交代脚步快慢，再写急停后衣摆或上身还顺势晃了一下。按已有地面和服装取舍。承重、喘息、站稳可以各选其一。 |
| 原句是否把不同任务的人都定位在同一处 | 按已给阵势安排前、中、后景。逐人交代交手者和相关旁观者盯着哪处、以什么状态应对，远景可用身体朝向与步态。背景人群可以合述。 |
| 相邻两镜的运动方向或动作进度有矛盾 | 看清上一镜最后的运动方向和进度。下一镜接后半段或结果；若原稿要求重放同一拍，再明确重放。 |
| 一镜到底塞了太多事 | 保住原镜头，按靠近、短暂交错、分开后的状态写成连续一段。用户指定的关键事件全部留着，先删陪衬和重复招式词。 |
| 动作参考和外观参考是否被指派了重叠的职责 | 给动作视频指定借用的节奏、动势、队形或运镜，人物和场景由各自的参考负责。参考已给足动作时，只补角色的情绪和最后落点。 |

## 一段可提交的讲戏示例

给定的戏是两人在台上比试，阿衡急于争先，阿宁到约定的鼓点就收势，阿衡迟一步才意识到比试结束。结尾阿衡服气，无对白。

> 【生成目标】
> 拍一段台上比试。鼓响后，阿衡比阿宁迟一步收住脚，最后以点头认服。
>
> 【事件脚本】
> 镜头一，台侧双人全景。画左近处的阿衡盯着右侧的阿宁，急于争先，重心已经往前。阿宁站得稍远，平静地看着他。两人向中央迎上，短暂对招后错身分开。阿宁停在画左，阿衡还向画右多走了一步。<鼓响一声>
>
> 镜头二，同侧中景。画左的阿宁应声放下手，从容地望向画右。画右的阿衡急着再上前，刚站稳就抬眼去看阿宁。看清对面收了势，阿衡的脚留在原处，肩膀还随呼吸起伏。
>
> 镜头三，只见阿衡的胸上近景，脸在画右。他望向画左，原本绷着的下颌松了些，认真点了一下头。
>
> 【约束】
> 无bgm，无字幕

若锁定同一全景，在原有构图里让左侧先收势，右侧多迈出的那一步停稳后才转身点头。让镜头留在两人之间的距离上，照样能读出阿衡从争先到服气。
