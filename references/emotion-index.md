# 情绪描述词检索表

每行给出一种通用情绪及两种取景下的演法。**提交时用情绪词配实际表演。** 从后两列选符合本镜的表现，再按这次的对象、时机和力度改写。如果词条只给注视方向，而本镜已经指定视线，保住视线，另选能读出态度的脸部或身体表现。例如「她有些委屈，下唇轻轻绷住，抬起的眼一直没移开」。两列是备选，单人镜头只取原有的人、物和事。

「嘴边的笑慢慢淡去」适合本来在笑的人。进镜时已经失落，可以写「她神情失落，视线一直落得很低」。近景写脸上看得清的变化，背影或全景写姿态，声音须符合原来的台词与声音条件。查到相近词时保留用户自己的用词和程度。词条里有与原稿相反的动作（如明说不笑）就另选能表现同一情绪的姿态。复合情绪先辨共存、掩饰和转变。

可从技能目录运行 `python3 scripts/lookup_emotion.py 失望 委屈 --limit 1`。输入多个词可并排比较。可按「先委屈再释然」的顺序查两种情绪。遇到未收录的情绪也保留原词，按可见部位为它编写表演。参见[同词的不同演法](emotions.md)和[表演分辨与声音](performance-precision.md)。
