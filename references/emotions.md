# 同一种情绪的不同演法

[完整检索表](emotion-index.md)提供可以组合进镜头的情绪词和通用表演。下表第一列点明情绪，后两列给不同的外露程度。提交时把原文的情绪分寸与选中的演法写在一起。轻微的静态表情也算表演。

| 情绪方向 | 情绪露出来一点 | 更明显的表演 |
|---|---|---|
| 她有些失望。 | 她神情失望，抬着的眼慢慢垂下。 | 她明显失望，原本前倾的身子一下松了下来。 |
| 她觉得委屈。 | 她有些委屈，下唇轻轻绷住。 | 她满脸委屈，眼眶渐湿，仍倔强地抬着脸。 |
| 他有些生气。 | 他压着怒意，说话的声音低下去。 | 他明显动怒，抬高了声音，收尾又急又重。 |
| 她有点害怕。 | 她神情害怕，呼吸轻了，肩头略收。 | 她吓得僵在原地，过了片刻才敢动。 |
| 他很高兴。 | 他嘴角浮起一点笑，眼神柔和下来。 | 他笑得露出上齿，上身都随笑声轻轻起伏。 |
| 她有些难过。 | 她神情难过，垂着眼安静了一会儿。 | 她悲伤得缓不过气，原本平稳的呼吸断了一下。 |
| 他有些尴尬。 | 他的笑停得稍久，慢慢收回来。 | 他局促地笑了两声，手势起了一半又放下。 |
| 她放松下来。 | 她轻轻呼气，下颌松开。 | 她长舒了一口气，整个肩背都松下来。 |

## 相近情绪怎么选

- **失望、委屈、失落。** 期待落空偏失望，觉得受了不公偏委屈，心里空了一块偏失落。这是选词时的区别。正文写所选的词，再用看得见的一笔演出分寸。同样是垂眼，失望可以慢慢放下原先期待的神色，委屈可以仍抬着眼、忍着辩解的冲动，失落可以安静地把目光放空片刻。
- **心虚、心疼、心动。** 都可能短暂躲开目光。心虚可以在回看时勉强维持镇定，心疼可以让眉间微蹙而眼神仍柔和，心动可以移开一点又忍不住看回去。同一眼神也可以服务完全不同的表演，以原文点名的感受为准。
- **害怕、受惊、后怕。** 害怕可以持续整镜，受惊的起势突然，后怕往往在紧张缓下来之后才显出来。持续状态可写「他仍有点害怕，下巴收着，肩头一直没松下来」。如果指定了起落，再写「肩头猛地一缩」或「肩膀已经松了，呼气仍有些不匀」。
- **自豪、得意、狂喜。** 自豪可以平静地站直一点，得意可以使嘴角的笑多留一拍，狂喜则可以使整个人的动作展开。用用户指定的分寸决定表现幅度。

## 复合情绪和强度

| 关系 | 情绪方向 | 怎样演出来 |
|---|---|---|
| 同时存在 | 高兴里带一点心酸。 | 笑得自然，眼里却慢慢有了湿意。 |
| 一层逐渐盖过另一层 | 起初真心高兴，后来有些失落。 | 眼睛先垂下去，笑还在嘴边留了一瞬才淡去。 |
| 想掩饰，但露出一点 | 表面平静，压着委屈。 | 开口时语调仍稳，停顿时下唇才绷紧。 |
| 明显转折 | 她先是紧张，渐渐安心下来。 | 原本绷着的肩膀放低，呼吸慢慢变匀。 |

先确认用户给的是持续、转折还是共存。单纯“失望”可以从开场持续到镜尾，低垂的视线也可以始终维持。只有原文含有期待、情绪刚刚发生或用户需要明显变化时，才写期待如何退去。愤怒可以安静、难过可以不哭、高兴也可以只有很小的笑意。用角色的习惯、当前强度和镜头可见部位来选。要同场示范可另看[完整案例](scenes.md)。
