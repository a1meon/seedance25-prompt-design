# 剧本、分镜与音色的处理规则

## 先读用户给的材料

按已有信息梳理在场和画外人物、道具归属、原句与说话人、用户的分镜与情绪。明确说“她很委屈”时沿用这个词，再补符合原有景别的表演。若剧本还给了她的意图、前后变化或掩饰程度，再据此调表演。反话、转述与全场气氛要结合语境判读。

## 分镜怎么处理

逐镜分清观众看见什么、只能听见什么、哪些信息只属于导演。用户给的是现成提示词时，先按[修订流程](prompt-revision.md)保住已有镜头和正确原句，再填这一镜的可见表演。

| 已给的信息 | 实际写法 |
|---|---|
| 没给分镜 | 先按剧本和场景摆好角色，找出哪一次靠近、停住或转向改变了彼此关系，再决定同框、切听者或移焦。静态情绪可用一个镜头。 |
| 已给完整分镜 | 沿用镜号、时长、景别、运镜、画内人物、指定动作和揭示时机。若运镜留白，保留原切点，沿走位、视线或戏意变化补具体运动。选择固定须能指出在移动中会丢失的表演或空间关系。若锁定机位，在画框之内设计可行的走位和回应；若连走位也锁定，就在原动作的节奏与可见部位上调表演。 |
| 给了零散设想 | 标出锚点，例如「先拍背影」「最后切钥匙」「中间一镜到底」。按锚点先后连接，只设计未指定的段落。用户说“最好能”是偏好，“全程固定”是硬条件。两项硬条件本身不可兼得才向用户确认。 |
| 只给情绪 | 直接使用清楚的情绪词，保留用户给的强度。多义词有上下文就依原文辨义；单人或纯表情需求使用通用措辞，配上当前取景能看清的表演细节。 |

**分镜决定哪里能演。** 面部近景可写「她有些失望，目光慢慢垂下」。固定背影中写「她有些失望，肩膀慢慢落下，头仍朝着原来的方向」。手部特写只写手的变化；若动作已经被锁定，先考虑微调该动作的节奏。

**时间与承接。** 发声时间优先留给原句。镜头太短先删配套动作，长句可以跨镜，画外声音继续属于原说话人。每次转折写清起始位置、触发和停在哪儿。下一镜从上镜已发生的结果出发。同一场独立生成多段时，复制这些段实际需要的戏服、物件和音色映射。

## 排素材与音色

读完本段镜头再排素材。分别记谁先入画、谁只在画外说话、哪些人有原台词。图片、视频、音频各按本类型的实际上传顺序编号，数字相同并不能证明图和声音属于同一个人。

- **能规划上传顺序时。** 人物外貌参考按首次实际入画排；同拍出场沿用分镜介绍顺序，多张造型图按同一人先后使用的造型排。人物音色沿用角色出场次序，只取有台词者。甲先露面，乙随后入画先开口，甲最后回答，两人都有台词时可排甲的形象和音色在前、乙的在后，镜内仍由乙先说。仅闻其声的角色按首次可听见的位置插入音色序列。先闻声后见人时，声音可先绑定，形象首次真正入画才参与图片排序。全段只有声音时按首次发声顺序排音色。场景、道具等各有其名；首尾帧、关键帧按其规定的时间顺序。
- **已经上传、指定或接续上稿时。** 先锁住每个真实槽位与身份，即使相对出场顺序不同。职责栏的人物形象行仍可按出场排列、声音行按上面的角色次序列出，各行保留真实编号。只有用户实际重排附件后才同步重编号。缺音色样本就按同一顺序预留可用号，跳过环境声、原声轨和未采用但已占用的编号。已上传的完整列表从其末尾续号。跨段沿用同一批素材时，同一人及其别名复用同一绑定，各段只列本段用到的。不同说话人各用自己的音色，用户指定共用声线时照用。换了一批附件则按新槽位重新对应。
- **一个标签，一个可复用的名字。** 在职责栏用角色名、道具名或具体的素材名，如「走廊母版」「进门走位示范」。同一素材兼用时只列一次，用其主用途或「母版参考」统称，具体继承项写回镜头或约束。多个素材必须区分时沿用用户给的最短名称。服装确为独立素材时可写「@图片3是礼服的服装参考。」事件句直接说谁在做什么，编辑和延长也直接称母版名。

| 情形 | 参考与事件中怎么写 |
|---|---|
| 一个说话人，未给音频 | 缺样本时照常分配编号，在【参考素材职责】写「@音频1为林岚的音色参考。」随后直接写镜头正文。 |
| 多人、已有部分参考 | 阿乔先入画，说话的师父随后出现。若阿乔与师父已分别绑定音频2和4，雨声占音频1，则依次写「@音频2为阿乔的音色参考。」「@音频4为师父的音色参考。」「@音频1为雨声参考。」再次出声时沿用原名。把角色姓名与实际原句放在对应镜头里。 |
| 画外、旁白、电话、录音 | 有可辨认台词就绑定实际发声者。电话里的阿乔仍用阿乔的编号；机内播放的他人录音按实际说话人处理。谁在画内闭口倾听要写清。无名独立旁白可以“旁白”为名。若本段只闻对白，仅列实际使用的声音参考。 |
| 原本就有原片或对白轨 | 用户要求原声照用或只改视觉时，保留原对白、现场声和声画关系。音色栏仍用简短映射；原对白的沿用要求写进对应片段。明确要求纯文字无音频引用、不要用外部音色或不另配音的要求优先。 |
| 无台词、集体声 | 没有台词的反应、喘息、哭笑、环境声不自动分配角色音色。真正有台词的齐声合唱按用户给的组合声轨或角色绑定。台词引述他人的话，音色仍属于眼下说出它的人。 |

最终绑定行用真实角色名替换 xx，写成「@音频1为小周的音色参考。」音色只负责声音身份。音高相对本人平常的变化、起声、重音、气口、语速属于这一次表演，在对应镜头交代。用户已给 @Audio 3 等平台等价标签时保留原标签。用户只说上传了音频时，结合上下文判断它是音色、原对白、音乐还是音效；仅有编号不足以定用途。不可把文件自带对白擅自当剧本，也不可因为有音色而给人物新编一句台词。
