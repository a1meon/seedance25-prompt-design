# 分镜、调度与讲戏

## 观众在这一镜知道什么

用户只要一个人的某种神情，一个镜头就可以拍完。先判断这次神情需要从何处被发现，决定从中近景靠近，还是让已清晰的脸在同一画框里演完转折。剧本有揭示时，再确定观众与角色同时明白、先于角色明白，还是只看到反应、稍后才知道原因。根据用户已有的信息顺序决定同框、切听者、移焦或延迟反打。

## 运镜和切点

**先看这项决定由谁做。** “全程不运镜”就固定拍，每镜可由演员调度来改变画面；“一镜到底”锁定连续拍摄，摄影机仍可按戏移动；两项都指定就同时遵守。“运镜不用写”则在交付正文里省去运镜说明。已给分镜只补镜内留白。只锁首尾时，保住两个锚点，在中间真正有情绪、氛围或信息变化的地方设计衔接。用户只改一个表情，其他摄影决定沿用有效稿。

**先画起幅和落幅，再选摄影机路径。** 先在两幅分镜上摆出同一侧的轴线、人物的远近、要保住的脸和预定揭示点。想清楚观众在哪一拍需要改看哪里，选一条能在本镜时长内走完的路径。例如演员在画右后方被近处肩线挡住，待近处人物让开，摄影机向画右短移，把后方那张脸带到两人之间；等脸清楚了，才让观众读到表情。用动作、声音、视线或有意的抢先揭示启动运动。落幅能接上下一镜。运动结束后停留读表演，整镜仍是运动镜头。

| 观众需要读到什么 | 写入本镜的拍法 |
|---|---|
| 从共同处境转到一人的决定 | 从双人中景起，在听者真正听懂时推近，收在听者胸上或面部。给关键反应留时间；要求一直同框时，改用短侧移打开两张脸的角度。 |
| 同行变成分开，有人决定留下 | 摄影机与同行者同速侧跟；其中一人停步，摄影机也停，另一个人继续走出画边。谁留下由落幅交代。 |
| 注意力换向，或新信息刚变得可见 | 只需转向时，在原机位随视线向画左或画右摇，写清最后带入什么。必须越过遮挡才看得到时，选短横移，先保住遮挡，到了揭示点才打开视线。 |
| 看清人物与空间的关系 | 从已在画内的主体缓缓后移，让原有空间逐渐进入画框；镜尾交代主体在空间中的位置。空镜也可以沿已有层次向前或向侧面移动。 |

**什么值得让摄影机始终不动。** 试想移动后的画面，指出它会损失的证据，再定固定机位。以下都是按戏选择的情形。

| 固定要保住的东西 | 怎样写到最终画面里 |
|---|---|
| 同时发生、谁先谁后才有意义 | 固定双人中近景，画左刚把手伸出，画右已把手收回，两张脸和两只手一直可见。若核心只在其中一张脸，可以随注意力靠近。 |
| 一个动作在同一空间里做完 | 从原位看两人完整错身、停定；若移动会遮住交错那一下或裁掉脚步，就留住全身和落点。路线超出画框时，改同侧平行跟移。 |
| 迟迟等不到回应、人物离开后留下的空位 | 双人构图里一人走出画右，摄影机固定，留下的人看向空出的那一侧，直到镜尾。观众须看到空位保持了多久。 |
| 信息必须到特定时刻才出现在边沿；前后必须精确对照 | 固定在原画框，让主体到指定时刻才入画，或让同一位置的变化显出来。若移动也能保住揭示顺序并让主体更清楚，可改用移动。 |
| 表演最要紧的是一瞬间的先后 | 起幅已能同时看清眼和嘴，保持这张脸的大小，看清笑意先收还是视线先避开。若从较远处起，可先靠近，关键一拍前停稳。 |

这些选择来自导演调度与分镜的做法。Steven D. Katz 用图解拆解长镜头中的走位、摄影机路线和连续的叙事变化；马修·利巴提克谈《鲸》时具体讲到怎样随演员调度重新建立视线；吕克·贝松谈《超体》时解释了为何在追逐中突然停在一个旁观者的视点，让观众等那个人作出反应。[《Film Directing: Cinematic Motion》](https://mwp.com/product/film-directing-cinematic-motion/) · [《鲸》摄影访谈](https://theasc.com/article/the-whale/) · [吕克·贝松访谈](https://theasc.com/post/the-film-book/interview-luc-besson-2/)

**只为尚未给出的镜头设计切点。** 在心里补完“切之前观众知道／感到什么，切过去发生了什么变化”。下列写法按戏挑一种，最终正文只留镜头本身。
 
| 这一切承担什么 | 什么时候切过去 | 如果保持原镜更好 |
|---|---|---|
| 读出情绪 | 发话者还在说，切给听者，让观众先看见他努力维持的平静。若指定某个词才明白，反应仍等到那个词。 | 双人构图已能同时看清试探和回避，就留在两人之间。 |
| 改变氛围 | 从拥挤的人群切到刚空下来的同一片空间，前一镜的喧声渐远，热闹后的冷清才显出来。使用剧本里已有的空间与声音。 | 空间本来尽收眼底，留住人走散后的几拍也能托住冷清。 |
| 交代信息或因果 | 先看清动作已经发生，再切到受它影响的人或物；观众要晚于人物得知答案时，先切反应，保留揭示。 | 同框就能完整看到交接或换位时，让动作做完再决定是否切。 |

指定快速甩镜或固定长镜时，把景别、表演与落点安排在用户选择的形式里。输入已经交代完整切点时，无须为补“节奏感”再加反打或插镜。

## 按剧本和场景安排角色调度

先在心里摆好演员。各人从哪里开始，想接近、留住、避开谁，谁在等回应？把这些意图放进用户给的地形、出入口、家具、可通行的空隙和既定站位里。正文只写本镜真正影响观众理解的空间关系。场景资料少时，用两人间距、身体朝向或原有动作设计调度。

- **选择谁先动，谁留在原地。** 根据人物的主动权和顾虑决定靠近、让出位置、错开目光或保持距离。双人戏里，一个人已经让开，另一个人却站着没走，可以同时交代两人的选择。静坐、独角戏和锁定脚位的镜头可用转脸、重心或手上动作完成同样的转折。
- **把动作落在具体一拍。** 需要走位时，从观众视角写起点、朝向、触发、路线和落点中真正有用的部分，再写对手可见的回应。台词若关键，弄清动作发生在开口前、说到哪个字时或话落后。群戏先定本拍主角，其他人用原来的位置或迟一拍的反应维持主次。
- **检查这条路和这个镜头。** 走道有多宽，中间是否隔着桌子，人能否在不穿过障碍的情况下到达落点？动作是否把关键表情遮住，已有构图能否看到？固定机位仍可容纳演员走动；用户锁定演员脚位则在原地演。近景只写能看见的上身、眼神或入画动作。镜头间承接上一镜结束时的位置、朝向、视线和物件归属，换机位后用新的画面左右来写。

**同一个意图的两种调度。** 剧本给“甲想挽留，最终让乙离开”。窄走廊里，甲原本站在去路上，固定双人中景可写「画左近处，甲望着从画右深处走来的乙，想挽留，嘴唇动了动，最后侧身让路。乙已经拿定主意，目光一直落在前面的通道上，步子没慢。乙经过时，甲的目光跟了半拍」。若两人隔桌坐着，机位锁定甲的胸上近景，可以写「甲望向画右，身子向前倾了些，原本想挽留，嘴唇动了动。最后靠回椅背，视线还留在原处」。

## 逐人安排情绪和视线

**过肩镜里的三个人要分清。** 贴着镜头的虚焦肩膀提供方位；被正拍的人要有情绪和面部表现；途中出现的第三人若脸也清楚，要另给他一笔。例如固定越肩中近景，左下仅有肩线，修表师始终望着画左，学徒从画右进来报喜。可以写「修表师望着画左，有些忐忑，眉头还拢着。画右的学徒满脸欣喜地笑开，朝修表师报了喜。修表师听清，眉间这才舒开，目光始终留在画左。」焦点可留在修表师脸上。学徒的喜悦和修表师的宽心各有归属，近处肩线无需交代脸。

转移视线时，两次落眼各承接什么态度？若态度有别，把区别写在转眼前后的神情上。多人同框时，主动者怎样发出邀请、施压或探问，承受者在哪一刻接住或避开，各自接到的刺激和回应可以错开。脸被前景遮住的人，等脸重新可见才落关键表情。无从知情的人照常做事。

一个人说话，另一个人未必看着他。从各自的处境选择目光的落点，譬如观察对方是否相信、避开对视、专注手上已有的工作，或继续等一个还没听见的回答。用户只写「委屈，仍看着对方」时，可以写「阿梨仍看着掌柜，有些委屈，刚要开口又合上嘴」。对方面对什么、有没有听懂，单独从这一段推断。一个人的猜测不能写成另一个人已经知情。镜内人物多时，主要的转变给足时间，其他相关人物各留一句短而清楚的表演。只有无关背景人群可合述或略过。

**固定三人中景的例子。** 柜台前，来客等退款，店长点头同意，店员负责办手续。用户指定来客委屈、一直看着台面。可以写「画左的来客有些委屈，一直看着台面，抿着嘴等。画右的店长平静地望向柜台中央的店员，点了一下头。店员原本看着店长等准话，见店长点头，紧提的肩松下来，低头办手续。」来客可以始终保持原来的神情。店员虽无台词，也有自己等待的信息和开始行动的时机。

## 每个机位的一张草图

主体在哪一侧、离镜头多远、观众看得清哪一部分？画中有前后层次时，分别定位近处遮挡、清晰主体与远处可见部分。只有单人面部特写时，可以只写画面中的脸。背影、倒影和越肩镜头按实际裁切描述。[逐镜可见范围](prompt-revision.md#逐镜可见范围)

- **画面坐标和人物坐标。** “往画左”是观众看到的横向运动，“往深处”会离镜头更远。要横穿，就写“沿同一排从画中向左出画，离镜头的距离基本不变”。写到人物自身的右手、右肩时明确是谁的右侧；只有机位与朝向足以判断时才换算成画面左右。正反参考图先按同一处空间对齐，随后分别取景。
- **双人反打。** 先确定两人是否相向、谈话轴在哪一侧。相向时，甲在画左朝右看，乙在画右朝左回看；并排望向同一处时，两人可以同向。切反打要接真实视线方向。明确只拍两个人的干净双人景，用两张脸与取景边缘锁定范围。是否包含前景肩线依用户取景。有意换轴时，可用连续移动、中性机位或全景重新交代朝向。
- **固定与移动。** 固定机位下，人靠近时占据的画幅变大。跟拍可让人物大小大致稳定，环境相对移动。只描述原镜能看见的参照。
- **主观视角、镜面、玻璃。** 观众借谁的眼睛看，镜头就保持其高度、俯仰和移动。视线仍朝地面时可以沿地面移动，等原定揭示点才带入新的人物。手持可写跟步的轻微起伏及停步后的回稳。镜面倒影、透过透明介质看到的人和被困在介质里的人分别按剧本原词处理；核对可见的是实物、反射或另一侧，勿凭镜像擅换持物手。
- **微表情是重点。** 脸部清楚的机位适合停留，给已有表情充分的可读时间。锁定背影或全景，就用头的朝向、肩背或动作节奏。取景内看不清的部位无需编排。
- **两种反应同样重要。** 构图能读出两人时可保留同框。只需看清一个人的反应时，将清晰度或切点交给那个人。画外人对镜内演员的影响可以通过视线和原有声音建立。

## 文戏的讲戏办法

| 镜头需要解决什么 | 可采用的处理 |
|---|---|
| 单纯情绪 | 保留原词和分寸，如「她有些委屈，抬着眼，下唇微微绷紧」。人物可以保持静止，镜头也可以停留。 |
| 同一句话有不同态度 | 语气、重音、气口选一处区分。关心可以把语尾放轻，压怒可以音量低、收字有力。台词依原文。 |
| 重点是倾听 | 声音继续时镜头可留在听者身上。原有一句话或停顿确实引起变化时，把听者的反应放在相应时刻。 |
| 掩饰与失守 | 定观众能察觉多少。想藏住可以照常行动；快维持不住时，原动作慢一点也够。已锁定静止时，保留细微神色即可。 |
| 哭戏 | 区分伤心、忍泪、已经在哭和哭后平静，保留原文给的程度。含泪可以安静，流泪也可以继续说话。 |
| 喜剧 | 对白、动作和反应之间的时差可形成笑点。人物可以一本正经；夸张幅度以用户指定风格为准。 |
| 群像 | 先定观众主要看谁，再逐人写同框者的注意落点和态度。安静等候、继续专注手里的事也是表演。只作环境的群众不必拆开写。 |

### 一句台词怎样在两张脸上演完

在已定的镜头和时长内，让反应有来有回。先看说者这一句想让对方做什么，再看听者实际给了多少回应。对试探的人，正面迎来的目光可能让他敢把话说完；对正想敷衍过去的人，同样的目光可能让他把原本顺口的后半句放慢。若他看不见对方，只从听得到的停顿或答复接戏。

| 剧本给出的分寸 | 可写进镜头的表演 |
|---|---|
| 想追问，又决定给对方留余地 | 说者眼里还有疑问，朝对方抬了抬眉。听者窘迫地避开目光。说者看见，原本要接话的嘴轻轻合上，让这段安静过去。 |
| 强忍委屈，仍想把话说清 | 人物始终看着对方，带着委屈。刚开口声音有点紧，等气息稳住才说完。切回时她仍迎着原来的目光，下唇还有些绷。 |
| 两个人都高兴，其中一人需要维持体面 | 一人听清就笑得眼角弯起，望向同伴要和他分享。同伴也高兴，迎上他的眼神才短短笑了一下，随后照常把手里的事做完。 |

只取当前景别、前情允许的一拍。第三人在场时，问他在留意说者、观察听者，还是有自己的事要顾，按他收到的信息落一处可见反应。跨切接住前一镜还留着的唇形、气息或未完成动作。若用到原有道具，接准谁还握着、谁已经松手，别让一次交接在反打里再来一遍。近景可停在动作将成未成处；短镜只留最能让人读懂态度的一处，持续的情绪也能静静演完。

## 武戏中的人物状态

处理整场武戏、已锁定的打戏分镜或生成后出现走位、身体重叠问题时，用[动作场面逐镜写法](screen-action.md)。

先沿用用户给的动作走向、空间关系和结局。在已有动作里调整节奏与收势，就能让同一段银幕交锋呈现不同的表演。关键情绪可以直接点名。

| 状态 | 双人或全身构图 | 能看清脸时 |
|---|---|---|
| 镇定、有把握 | 重心安稳，动作收得干净。 | 神情镇定，目光保持在原来的方向。 |
| 逞强 | 上身仍挺直，调整重心比刚才迟了一拍。 | 勉强笑一下，随即收紧下颌。 |
| 失势、不甘 | 原动作顿住，重新站稳时身形仍朝前。 | 表情受挫，抬眼时仍带着不甘。 |
| 从戒备到敬重 | 紧绷的姿态逐渐放松，动作完整停稳。 | 下颌松下来，看得更坦然。 |
| 紧张已过、心有余悸 | 动作已经结束，手还微微发颤。 | 肩膀刚松下来，呼气仍不太匀。 |

既有大动作承担信息时，可保持全身构图。叙事重点转到人物的选择且允许切镜时，再在停步或收势处切近景。单凭喘息也可能只是疲劳，需要区分时，可以写「他还有些后怕，肩膀松下来手才开始抖」或「他已经累极了，弯着上身，呼气拖得很长」。完整的文戏、武戏运用见[独立案例](scenes.md)。
